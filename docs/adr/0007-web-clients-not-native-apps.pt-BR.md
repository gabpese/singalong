# 0007. Celulares e TV são páginas web, não apps nativos

[English](0007-web-clients-not-native-apps.md) · **Português (Brasil)**

Um convidado numa festa não instala nada: lê o QR code da TV e já está dentro. Qualquer navegador pode ser a TV, a troca de tom roda no navegador sem reprocessar a música, e o app instalável do Dono mostra essas mesmas páginas. Um app nativo pediria a cada convidado uma instalação antes de cantar.

## Alternativas consideradas

- **Flutter ou apps nativos**, sugeridos numa revisão para reduzir o número de linguagens: rejeitado; cada convidado precisaria instalar algo, e o worker continuaria em Python ([ADR 0004](0004-python-worker.pt-BR.md)).
