Administração do Singalong

Digite o token de administrador (o ADMIN_TOKEN do servidor). Ele fica só nesta aba do navegador.

O envio de e-mail não está configurado neste servidor (BREVO_API_KEY e MAIL_FROM): ninguém consegue pedir código pelo app.

Versão do app

O que os apps instalados veem. Quem está abaixo da versão mais recente recebe o aviso "Atualizar agora" com a mensagem; quem está abaixo da mínima para de receber trabalho do servidor até atualizar. Vale na hora, sem reiniciar. A página inicial também mostra a versão mais recente e o endereço de download.
